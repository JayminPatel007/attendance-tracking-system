# Sabha Attendance — Mobile

Flutter app for Sanchalak / Sah-Sanchalak per ADR-0003.

## First-time setup

Platform directories (`android/`, `ios/`) are generated by Flutter rather than hand-written. After installing the [Flutter SDK](https://docs.flutter.dev/get-started/install) (>= 3.22), bootstrap them in this directory:

```bash
flutter create --platforms=android,ios .
flutter pub get
flutter test
```

## Tests

```bash
flutter test
```

Cycle 3 ships:

- `lib/main.dart` — `SabhaAttendanceApp` with a splash screen.
- `test/splash_test.dart` — widget test asserting the splash renders the app title.

Subsequent slices (#3 onwards) add the login flow, Roster, offline cache, and sync queue.
